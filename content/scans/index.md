## Products, by configuration

A product is not a deployment: it has no owner, no policy in force and no mandate until somebody runs it. So a product gets a freedom level for each configuration and a list of the controls each brings, and no governance level. Each is built only from the vendor's own documentation and published profiles, has not been seen by the vendor, and will be corrected on request.

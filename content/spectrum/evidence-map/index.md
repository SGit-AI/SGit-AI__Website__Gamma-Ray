# The evidence map

Each cell is reached when particular indicators have public evidence. The rules below are the ones the scorer runs; they are data, in [spectrum.json](../../data/spectrum.json).

{{gen:spectrum-map}}

## How a rule is read

- "one of" is met by any of the listed facts; "and" needs all of them; "2 of" needs any two.
- A public card counts every documented fact about a product, whether it holds as shipped or has to be turned on. A fact that has to be turned on is marked "available" on the card.
- For Control level 3, the facts (it is logged, it can be paused, it is monitored) are read as product features that exist. Whether a given deployment uses them is a question for the layer above.

## The three indicators added for Spectrum

Each has its links to provisions, the kind of each link, the basis in writing, who asserted it and when. All were asserted by one reader and are marked weak until a second reader has checked them.

# GAMMA-Ray

The source of [gamma-ray.sgit.ai](https://gamma-ray.sgit.ai/): a draft standard that rates an AI agent on its freedom and its governance, from evidence, by joining public maturity standards into one short list of questions.

- `BRIEF.md`: the brief, in the operator's words. `BRIEF-CORRECTIONS.md`: where its sources were wrong.
- `REALITY.md`: what exists. A thing not in it does not exist.
- `data/`: the instruments, the provisions, the indicators, the questions, the levels and the scans.
- `content/`: the pages, in markdown. `assets/`: the stylesheet and one script.
- `build/`: `node build/build.mjs` builds `_site/`; `node build/validate.mjs` is the gate and must print OK.
- `CLAUDE.md`: the rules for agents working here.

Work on `dev`. CI numbers every push; nobody else writes the version. Our own writing is CC BY 4.0, the code Apache 2.0; each instrument keeps its own licence.
